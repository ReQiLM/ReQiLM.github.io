常见问题

帮 AI 和搜索引擎：直接有 HTML 表格，不用运行 JavaScript

Windows 提示"已保护你的电脑"
这是 Windows SmartScreen 对未签名程序的默认提示。点击「更多信息」→「仍要运行」即可。软件没有数字签名，但代码完全开源，可以自行审查。
杀毒软件报毒、文件被删
部分杀毒软件可能误报。请将程序目录加入白名单。软件不注入、不读内存、不模拟输入，不会触发游戏反作弊。
认不出英雄或海克斯
确认游戏设为「无边框」或「窗口化」模式。全屏独占模式下截不到画面，OCR 无法识别。另外确认游戏窗口在前台。
会不会封号
不会。软件只截图识别，不读取游戏内存、不注入、不模拟输入、不发送任何游戏指令。只读 LCU 获取本人英雄信息。
数据多久更新
每周更新。数据来自公开数据仓库，免费可用，不需要 API Key。
不用 API 能用吗
可以。英雄胜率、海克斯评级（S/A/B/C/D）、出装加点都是内置数据，无需 API。只有单个海克斯的详细胜率需要 API。
