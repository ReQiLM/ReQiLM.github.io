# HexRank

海克斯大乱斗胜率助手

在线版：https://reqilm.github.io/

## 功能

- 英雄胜率、选取率、场次、排名
- 海克斯 S/A/B/C/D 评级推荐
- 出装与技能加点
- 分段数据（娱乐/中分/前5%）

## 使用

1. 游戏设为无边框或窗口化
2. 运行 HexRank
3. 自动识别英雄和海克斯

## 数据

数据来自公开数据仓库，每周更新，无需 API。
